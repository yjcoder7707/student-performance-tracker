# 🎓 Student Performance Analytics System

A Python and NumPy-based project that analyzes student academic performance and generates meaningful insights from student marks.

## 📌 About the Project

The **Student Performance Analytics System** is a beginner-friendly data analysis project developed using Python and NumPy.

It generates a dataset of 100 students across 5 subjects and performs different types of analysis, including performance evaluation, statistical analysis, data normalization, outlier detection, and grade classification.

The main goal of this project is to understand how NumPy can be used for numerical computing and real-world data analysis.

## ✨ Features

- Generate synthetic student marks using NumPy.
- Calculate total marks and average scores.
- Identify class toppers and top 5 students.
- Analyze subject-wise performance.
- Calculate pass and fail statistics.
- Calculate mean, median, variance, and standard deviation.
- Generate covariance and correlation matrices.
- Perform Min-Max Normalization.
- Perform Z-score Standardization.
- Detect outliers using the IQR method.
- Assign grades based on student averages.
- Categorize student performance.
